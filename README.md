# Homebrew Tap for macOS Apps

Custom [Homebrew](https://brew.sh) tap containing macOS applications created by [@qn34uc59t](https://github.com/qn34uc59t).

---

## Available Casks

| App | Description | Install Command |
|---|---|---|
| [**PrivacyScreen**](https://github.com/qn34uc59t/privacy_screen) | Intelligent head-tracking privacy shield using CoreMotion and AirPods | `brew install --cask qn34uc59t/tap/privacyscreen` |
| [**SPIA**](https://github.com/qn34uc59t/spia) | Intelligent camera motion surveillance and alert dispatch for macOS | `brew install --cask qn34uc59t/tap/spia` |

---

## Usage

### Install an Application

```bash
# Install PrivacyScreen
brew install --cask qn34uc59t/tap/privacyscreen

# Install SPIA
brew install --cask qn34uc59t/tap/spia
```

### Update Applications

```bash
brew upgrade privacyscreen
brew upgrade spia
```

### Uninstall Applications

```bash
brew uninstall --cask privacyscreen
brew uninstall --cask spia
```
