# Homebrew Tap for PrivacyScreen

Custom [Homebrew](https://brew.sh) tap for installing [PrivacyScreen](https://github.com/qn34uc59t/privacy_screen) — an intelligent head-tracking privacy shield for macOS.

## Installation

```bash
brew install --cask qn34uc59t/tap/privacyscreen
```

## Update

```bash
brew upgrade privacyscreen
```

## Uninstall

```bash
brew uninstall privacyscreen
```
